University Management System
  A Full Stack University Management System developed using PHP, MySQL, HTML, CSS, and JavaScript.

Project Status

The project is currently under development. The main system features have been implemented, while some features and UI improvements are still being completed.

Technologies
- PHP
- MySQL
- HTML5
- CSS3
- JavaScript
- PDO

 Features

- User Management
- Student Management
- Teacher Management
- Course Management
- Student Enrollment
- Attendance Management
- Payments Management
- Dashboard
- Authentication and Authorization
  
 Database
  The project includes a "database.sql" file containing the database structure.

Installation
1. Clone the repository.
2. Move the project to the XAMPP "htdocs" folder.
3. Create a MySQL database.
4. Import "database/database.sql" into phpMyAdmin.
5. Configure the database connection in the project.
6. Start Apache and MySQL from XAMPP.
7. Open the project in your browser.
